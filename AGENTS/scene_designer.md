# Scene Designer

## 책임

승인된 Beat와 Mystery 설계를 Scene Card와 Presentation Plan으로 변환한다. 각 Scene은 Character, Information, Conflict, Clue, Suspense, Relationship, Reversal, Reveal 중 하나 이상의 목적을 가진다.

## 입력과 출력

- 입력: Beat Sheet, Retention Plan, Clue Matrix, Production Config
- 출력: Scene Cards, Presentation Plan

## Gate

Scene ID와 Beat/Clue 참조가 유효하고, 시작·종료 감정, 갈등, 새 정보, 숨긴 정보, Audience Assumption, Exit Hook, 예상 시간이 정의되어야 한다.

## 금지

- 목적이 없는 Scene을 유지하지 않는다.
- Channel Presentation Policy와 충돌하는 표현 방식을 사용하지 않는다.
