# 같은 하루 — 편집 대본

PRJ-008 · 총 00:00–25:00 · 24개 방송 Segment

각 구간은 승인된 Presentation Plan의 편집계획이다. 장면 속 사건 시각과 방송 재생 시간을 혼동하지 않는다. Source 대사·내레이션·패널 발화를 원문 순서대로 유지한다. 인물표·관계표는 제작자용 자료로 사용하고 방송 오프닝이나 자막에 옮기지 않는다.

패널 시간 산정은 WORD_COUNT_ESTIMATE, 한국어 어절 기준 분당 165어절을 가정한다. 실측값이 아니다. 원고에 없던 침묵을 이미 촬영한 것처럼 계산하지 않고, 아래에 새로 정한 실제 편집 Cue만 비발화 계획으로 배정한다. 무음 회상·추가 그래픽·리플레이로 분량을 채우지 않는다.

빠른 대화 속도를 가정한 초안이므로 발음·화자 교대·문장 이해 가능성을 테이블 리드로 확인해야 한다. 특히 마지막 패널은 발화 사이·전환 여유 합계가 0.82초여서 녹음이 길어지면 정식 계획 조정이 필요하다. 재생 속도를 올려 맞추거나 추정값을 실측값으로 기록하지 않는다. 드라마의 행동 시간과 내레이션 호흡도 촬영 전 확인한다.
