# 같은 하루 · 자막 원문·구간 계획

제작 메타데이터: PRJ-008 · 방송 계획 25분 · 전체 24구간.
표시된 시작·종료는 Presentation Plan의 방송 전역 구간 경계다. SRT나 녹음 실측 타임코드가 아니며, 개별 자막의 인·아웃과 줄 나눔은 녹음·편집 후 확정한다.
각 항목에서 인용 블록만 화면에 사용하는 원문이다. 구간 제목, 항목 번호, 화자·유형, 시간과 HTML 주석은 제작 메타데이터이며 방송 자막에 올리지 않는다. 문자와 메모의 이름은 읽는 사람이 아닌 작성자를 나타낸다. 인물 역할표나 사건 해설을 도입 자막으로 추가하지 않는다.
발화·독백·내레이션·패널 발화와 이미 계획된 문자·메모·화면 문구를 원문 순서대로 보존했다. 지문과 내부 사실·사건·피해 추적 표시는 자막 원문에서 제외했다. 첫 구간의 창작 고지도 현재 원문대로 포함한다.
