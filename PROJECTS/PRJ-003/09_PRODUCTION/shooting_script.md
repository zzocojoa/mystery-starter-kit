# PRJ-003 촬영 대본 — 열한 번째 인터뷰

## 제작 기준

- 총 편성: 25:00 / 12개 장면 / 단일 야간 로케이션 `모월재 게스트하우스`
- 화면 문법: 현재 인터뷰는 안정된 삼각대, 수색은 짧은 핸드헬드, 과거 원본은 4:3 프레임과 낮은 채도, 패널은 외부 스튜디오 고정 3샷
- 음향 핵심: 자동 스피커 전자음, 마루의 `끽—끽—끽`, 녹화 모니터 릴레이음. 세 소리는 서로 대체하지 않는다.
- 소품 핵심: 붉은 인터뷰 토큰, 번호 없는 검은 테이프 열쇠, `RAW / 5Y` microSD, 금속 물병, 3번 소프트박스
- 안전·존엄: 결박은 실제로 조이지 않고 의상 안쪽 분리형 밴드를 사용한다. 한유진의 피해 경험은 충격 이미지로 재연하지 않으며, 마지막 공개 범위 결정은 한유진의 대사와 행동으로 촬영한다.

## SCN-01 — 비어 있는 감독석 (SEG-001, SEG-002 / 00:00–01:50)

- 로케이션: 라운지. 24mm 마스터에서 빈 붉은 의자와 여섯 인물을 한 프레임에 둔다.
- 인서트: `18:47`, 전체 예약 안내, `DIRECTOR` 빈 칸, 윤서나의 마지막 메시지.
- 연기: 강태준의 삭제 고백 때 한유진 리액션을 먼저 잡고, 고백자를 영웅화하는 푸시인은 금지한다.
- 전환: 박민규 손이 붉은 토큰 위에서 멈춘 채 스피커 음성으로 컷. SEG-002는 빈 의자와 과거 편집 타임라인 B-roll 위 VO.

## SCN-02 — 세 초 전의 문장 (SEG-003–SEG-005 / 01:50–03:50)

- 50mm 인터뷰 투샷. 붉은 토큰 QR과 자동 자막 타임코드를 매크로로 확보한다.
- 박민규의 부인 직후 `19:07:18 → 19:07:21`을 3초 동안 실시간 유지한다.
- 신호 단절은 검은 화면과 한 번의 숨소리로 처리하고 과도한 충격음을 쓰지 않는다.
- 패널 RSEG-001 진입 전 8프레임 블랙. 스튜디오 뒤 그래픽은 `반복 문장 → 3초 → 신호 단절`만 표시한다.

## SCN-03 — CAM-11 (SEG-006–SEG-008 / 03:50–05:55)

- 납치 화면은 고정 35mm, 검은 흡음막, 낮은 키라이트로 촬영한다. 윤서나의 손목에는 실제 압박 자국을 만들지 않는다.
- `CAM-11`, 물병 속 뒤집힌 `3`, 세 번의 마루 소리를 같은 숏에 공정하게 노출한다.
- 현장 인물의 공포 반응과 윤서나 화면을 분할하지 말고 교차 컷하여 단서 과잉 강조를 피한다.
- 패널 RSEG-002에서 `CAM-11 ≠ 11번 방` 그래픽을 최초 사용한다.

## SCN-04 — 나간 사람은 없다 (SEG-009–SEG-011 / 05:55–07:55)

- 관리자실 CCTV를 어깨너머로 촬영한다. 윤서나 입장 뒤 출구 기록 부재를 한 번만 풀 재생한다.
- 서비스 계단과 주방 사각지대는 평면도 그래픽에 점선으로 표시하되 암실 위치는 숨긴다.
- 번호 없는 열쇠는 최도식의 손과 박민규 시선의 매치 컷으로 제시한다.
- RSEG-003은 관리인 유죄 확정처럼 보이지 않도록 화면 하단에 `현재 가설` 표기를 유지한다.

## SCN-05 — 열 개의 문 (SEG-012–SEG-014 / 07:55–09:55)

- 객실 수색은 1–10 번호판 몽타주와 각 문 내부 한 컷으로 압축한다. 사람 없는 방을 공포 이미지로 과장하지 않는다.
- 토큰 바닥 `AUDIO M-01`을 2초 이상 보여 준다.
- 배지아가 microSD를 숨기는 동작은 관객에게 보이되 다른 인물 시선축 밖에 둔다.
- RSEG-004 뒤 `숫자의 용도를 바꿔 읽어라` 키워드 그래픽으로 전환한다.

## SCN-06 — 방 번호가 아닌 숫자 (SEG-015–SEG-017 / 09:55–11:50)

- 스위처 GUI의 `CAM-01 … CAM-11 / LIVE`를 실제 재생 가능한 화면으로 준비한다.
- 외부 네트워크 주소가 없고 로컬 입력임을 커서 이동 한 번으로 보여 준다.
- 비어 있는 3번 삼각대와 벽 뒤로 이어진 케이블을 35mm 트래킹으로 연결한다.
- RSEG-005 마지막에는 모월재 평면도 전체를 다시 보여 주지 않고 촬영계 블록도만 사용한다.

## SCN-07 — 복도가 영상 안으로 들어오다 (SEG-018–SEG-020 / 11:50–13:55)

- 현장 마이크와 영상 파형을 동일 화면에 합성한다. 세 봉우리가 겹치는 순간에만 짧은 강조음을 사용한다.
- 강태준의 마루 재현은 같은 보폭과 세 번의 소리로 한 테이크 촬영한다.
- 최도식의 주방 쪽 시선은 반응 숏으로 남기되 범인 확정 음악은 사용하지 않는다.
- RSEG-006은 복도 B-roll과 파형 리플레이를 합쳐 비발화 호흡을 확보한다.

## SCN-08 — 같은 카메라의 두 얼굴 (SEG-021–SEG-023 / 13:55–16:10)

- 인터뷰/납치 화면 분할에서 일련번호와 연속 프레임 카운터를 동시에 읽을 수 있게 한다.
- 물병 반사는 좌우 반전 복원 애니메이션 뒤 `3` 스티커에 1초 정지한다.
- 잠긴 문 앞에서 최도식과 강태준을 대칭 배치해 접근권과 제작 책임을 시각적으로 분리한다.
- RSEG-007은 `피해자 / 제작자` 이분법을 물음표로 제시하고 결론 자막을 선행하지 않는다.

## SCN-09 — 너무 완벽한 범인 (SEG-024–SEG-026 / 16:10–18:20)

- 암실 문이 열릴 때 와이드 한 컷으로 빈 의자, 3번 소프트박스, 물병, 카메라를 모두 보여 준다.
- 최도식 추궁은 얼굴 클로즈업보다 공간 협조 사실과 촬영 로그 부재를 교차한다.
- 사용자명 `YSN`과 자동 업로드 프로그램은 배지아의 확인 뒤 공개한다.
- RSEG-008에서 `접근권 ≠ 촬영 입증` 그래픽을 사용해 거짓 해답을 닫는다.

## SCN-10 — 거짓말이 재생 버튼이 될 때 (SEG-027–SEG-029 / 18:20–20:45)

- 과거 원본은 왼쪽, 현재 인터뷰는 오른쪽. 한유진의 원본 대답은 잘리지 않은 호흡으로 유지한다.
- `부인 문장 감지 / 3초 뒤 공개 시작` 로그를 현재 절대시각 없이 제시한다.
- microSD 실물과 공개 절차 연결 화면을 한 축으로 촬영한다.
- 린넨 보관실 아래 붉은 녹음등을 SCN-11 연결 숏으로 사용한다.
- RSEG-009의 윤리 반응까지 끝난 뒤에만 윤서나의 직접 등장을 허용한다.

## SCN-11 — 열한 번째 인터뷰의 주인 (SEG-030–SEG-032 / 20:45–23:15)

- 동선 재구성은 현장 위 그래픽으로 `현관 → 사각지대 → 암실 → 서비스 계단 → 린넨실` 순서만 표시한다.
- 윤서나 등장 첫 숏은 전신 와이드로 안전 상태를 명확히 한다. 상처 클로즈업이나 구조 영웅 숏은 금지한다.
- 대립의 중심은 자작 여부보다 동의 없이 빼앗긴 선택권에 둔다.
- 한유진의 “두 사람의 속죄에 제 대답을 미리 넣지 마세요” 뒤 2초 무음 홀드.
- RSEG-010은 한유진 없는 자리에서 용서를 대신 선언하지 않으며, 공개 진실과 관계 회복을 분리한다.

## SCN-12 — 공개 이후 (SEG-033, SEG-034 / 23:15–25:00)

- `20:10` 안전 확인문과 조작 고백 업로드 완료를 실시간 화면으로 촬영한다.
- 한유진이 microSD를 직접 집고 공개 범위를 정하는 행동을 결말의 주도 숏으로 삼는다.
- `DIRECTOR` 칸이 `윤서나 / 조작 공개`로 바뀐 뒤 녹화를 끄지 않는 강태준의 손을 보여 준다.
- 마지막은 열린 현관 와이드. 누구도 먼저 나가지 않는 3초 정지 뒤 SEG-034 VO와 함께 천천히 페이드아웃한다.

## 현장 연속성 체크

- 베이지색 코트는 SCN-01 CCTV 인서트와 SCN-11 등장에 동일 소품을 사용한다.
- 붉은 토큰의 QR 방향, microSD 라벨, 번호 없는 열쇠의 검은 테이프 방향을 장면별로 사진 기록한다.
- 스위처 입력명, 프레임 카운터, 업로드 UI는 촬영 전 고정 렌더링하고 후반에서 문구를 바꾸지 않는다.
- 현재 시간 자막은 `18:47 → 19:00 → 19:54 → 20:00 → 20:10` 순서만 사용한다.
