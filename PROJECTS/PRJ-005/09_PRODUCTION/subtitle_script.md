# PRJ-005 자막 대본

원칙: 대사 자막은 최종 대본의 의미를 축약하지 않으며, 증거 자막은 화면에 실제 등장한 문구와 시각만 표시한다.

| 구간 | 자막 / 화면 문구 |
|---|---|
| SEG-001 | [효과음] 첫 번째 종 · [효과음] 두 번째 종 · [효과음] 세 번째 종 |
| SEG-002 | 세 번째 소리가 가까워졌을 때, 그 믿음부터 버려야 했다. |
| SEG-004–005 | 폐기 목록 18-44 / 상자 봉인 18-47 · 누락된 번호 하나 |
| SEG-006 | 예정되지 않은 점검 · 통화 종료 17:42:10 |
| SEG-009 | 내부 레버: 외부 잠금 불가 · [문 잠금음] |
| SEG-011–012 | 한 번의 진동 · 카트 아래 비상 키 |
| SEG-014–015 | 동일 시각 / 서로 다른 종 위치 · 서로 반대인 카트 기록 |
| SEG-017–019 | 보지 못한 것은 보았다고 말하지 않는다 · 기억의 빈칸은 사고의 증거가 아니다 |
| SEG-020–022 | 실제 간격 20초 · 최단 이동 54초 · 단독 행동 불가능 |
| SEG-023–025 | 세 번의 종: 구조 신호 → 위치 신호 · 사진 + 통화 시각 + 점검 기록 |
| SEG-026 | 공동 행위: 지시 / 출입 / 위치 신호 · 동기: 예산 기록 은폐 |
| SEG-027–029 | 자유 박탈 · 손목 부상 · 닫힌 공간에 남은 공포 |
| 엔드 카드 | 본 이야기는 창작입니다. |

화자 표기는 해온, 수빈, 감사관, 패널 1–3으로 통일한다. 문자·채팅·메모·녹음은 화면 원문과 동시에 읽을 수 있는 위치에 배치한다.
