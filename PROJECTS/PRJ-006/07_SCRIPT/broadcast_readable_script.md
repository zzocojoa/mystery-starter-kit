# 「폐장 음악이 멈춘 7분」 방송용 가독형 스크립트

## 정리 기준

- `final_script.md`는 기계형 Broadcast Master로 별도 유지한다.
- Drama·Narration은 Canonical Screenplay Unit 원문을 보존한다.
- Panel은 Canonical Reaction Turn 원문과 전역 Presentation 순서를 보존한다.
- 내부 Marker·Canonical ID는 사람용 문서에 표시하지 않는다.

*[상황 설명: 장소 — 사건 밤을 재연한 제어실, 차폐가 내려간 창 앞 / 시간 — 사건 발생 20분 전의 실제 회의를 재연 / 직전 장면 — 장면 8. 세 자리의 공통점 / 시작 인물 상태 — 강태수가 오민재와 박도윤을 문 안쪽으로 불러 한지석의 원본 점검표 사진을 보여 준다. / 시작 감정 상태 — 범행의 목적과 역할 분담이 언어로 확정되는 압축된 공포 / 관객 정보 획득 — 안전 기록 조작과 내부 고발 차단이 세 사람의 공통 동기였다.]*

*[음향·행동 설명: 배경 음악 — 밖의 폐장 음악이 문 넘어로 흐르고 회의실 안은 무음으로 남는다. / 환경 음향 — 강태수가 제어실 문의 수동 잠금장치를 건다. / 점검표 원본이 책상 위에 낮게 내려진다. / 행동 개요 — 강태수가 조작 전 점검표의 유출을 막기 위해 두 직원에게 피해자 분리와 퇴로 차단 역할을 나눠 준다.]*

*[지문: 강태수가 한지석의 원본 점검표가 찍힌 화면을 뒤집어 놓는다. 그 앞에 오민재와 박도윤이 서로 떨어져 서 있다.]*

**강태수** *(녹음에 남을 수 있다는 가능성을 생각하지 않고 낮고 단호하게 말한다.)*
원본이 나가면 우린 모두 끝나.

**박도윤** *(거부처럼 시작하지만 끝에서 시선을 내린다.)*
점검표만 되찾으면 되잖습니까. 사람을 건드릴 필요는 없어요.

**강태수** *(책임을 공통 위기로 바꾸어 두 사람을 묶으려 한다.)*
내일 아침이면 계약도 끝나고, 이 기록에 이름 들어간 사람도 끝나. 오늘 여기서 멈춰야 해.

*[지문: 강태수가 평면도의 풀 쪽에 오민재의 카드를, 스피커 옆에 박도윤의 카드를 놓고 자신의 카드는 제어실에 남긴다.]*

**강태수** *(비선정적이지만 역할 분담이 명확하게 평면도를 짚으며 말한다.)*
한지석은 내가 붙잡지. 정세린은 통로로 나가지 못하게 해. 음악이 끊기면 움직여.

*[지문: 오민재와 박도윤은 대답하지 않는다. 다만 강태수가 놓은 자신들의 카드를 각자 주머니에 넣는다.]*

**화면 문구**
공통 동기: 안전 기록 조작 은폐 · 내부 고발 차단

**정세린(내레이션)** *(사후적 이해가 감정을 앞지르지 않도록 차분하게 말한다.)*
나는 오랫동안 그 밤의 방향을 외웠다. 하지만 그들은 이미 내가 보기 전에 자기 자리를 나눠 갖고 있었다.

**정세린(내레이션)** *(자신의 기억을 절대화하지 않고 증거와 분리한다.)*
기억이 내게 돌아온 것은 아니다. 증거가 기억의 두려움을 옮겨 주었을 뿐이다.

*[반전 후 의미: 유리에 비친 세 소매는 우연히 같은 장소에 있던 세 사람이 아니라, 조작 기록을 숨기려 역할을 나눈 공범의 동선이다.]*

## 장면 10. 세 시계가 움직인 순간

*[상황 설명: 장소 — 실내 수영장과 관리 통로를 한 화면에 나눈 비선정적 범행 재구성 / 시간 — 사건 밤의 음악 중단부터 은폐 시점까지의 순서를 압축 재연 / 직전 장면 — 장면 9. 원본이 나가기 전 / 시작 인물 상태 — 한서윤이 평면도, 원본 점검표, 단추, 스피커 로그를 앞에 놓고 재연의 순서를 한 단계씩 멈춘다. / 시작 감정 상태 — 범행 방식을 선정적으로 재현하지 않으면서도 세 사람의 책임 순서를 틀리지 않으려는 결연함 / 관객 정보 획득 — 세 공범이 폐장 권한을 이용해 두 피해자를 분리하고 공격한 뒤 사고와 단독 침입으로 위장한 방식이 확정된다.]*

*[음향·행동 설명: 배경 음악 — 음악 중단 후 짧은 타격음 대신 시계 초침과 문 닫히는 소리로 순서를 만든다. / 환경 음향 — 폐장 음악이 멈춘 뒤 세 개의 시계가 같은 분을 가리킨다. / 두 문이 다른 시점에 닫히고 물결 소리가 빈 공간에 남는다. / 행동 개요 — 음악 중단, 피해자 분리, 관리 통로 차단, 비선정적 치명 폭력, 점검표 교체의 순서를 역할별로 복원한다.]*

*[지문: 음악이 멈춘 순간, 세 사람의 시계가 같이 움직였다.]*

*[지문: 유리 벽에는 세 방향의 소매가 순서대로 스친다.]*

*[지문: 박도윤이 폐장 음악을 끊는 장면 뒤로 오민재가 관리 통로의 퇴로를 차단하고, 강태수가 한지석을 풀 쪽으로 분리하는 화면이 이어진다.]*

*[지문: 폭력은 그림자와 닫힌 문으로만 암시된다. 한지석의 안경이 물 위에 떠오르고, 정세린이 찢어진 소매를 붙들고 다른 문으로 빠져나간다.]*

*[지문: 강태수가 조작 전 점검표를 금속 함에 넣고 수정본을 제어실 클립보드에 끼운다. 오민재와 박도윤은 각자의 시각을 공식 폐장 기록에 맞춘다.]*

**강태수** *(실수로 내뱉은 사실을 다시 담을 수 없는 순간처럼 목소리가 낮아진다.)*
정세린은 관리 통로로 나온 사람을 하나로 기억했어. 음악을 이용해 서로를 나눠 놓은 뒤였지.

**한서윤** *(오빠의 유품이 아닌 증거로서 점검표를 처음 호칭하듯 말한다.)*
점검표는 범행 후에 새로 만든 해답이 아니에요. 그들이 누구를 왜 분리했는지를 범행 전부터 남긴 원인이에요.

**화면 문구**
재구성: 지시 → 분리 → 비선정적 공격 → 기록 교체 → 사고 위장

*[지문: 평면도의 세 화살표가 하나의 사건 표식으로 묶인다. 화면은 피해의 결과를 보여 주기 직전에 멈춘다.]*

*[반전 후 의미: 원본 점검표는 단순한 안전 문서가 아니라 피해자 선정, 공범의 동기, 은폐 시도를 하나의 인과로 묶는 증거가 된다.]*

## 장면 11. 한 사건의 두 피해

*[상황 설명: 장소 — 정리된 제어실 기록대, 한지석의 빈 의자와 정세린의 의자가 나란히 있다. / 시간 — 재구성을 마친 당일 밤 / 직전 장면 — 장면 10. 세 시계가 움직인 순간 / 시작 인물 상태 — 한서윤은 범행 순서와 두 피해 결과를 한 장의 사건 기록으로 정리하고, 정세린은 보지 못한 부분을 표시한다. / 시작 감정 상태 — 개인적 복수보다 검증된 책임을 남기려는 애도와 절제 / 관객 정보 획득 — 한 명은 사망하고 한 명은 중상으로 살아남았으며, 물리 흔적·제한된 증언·원본 기록이 세 공범의 공동 책임을 확정한다.]*

*[음향·행동 설명: 배경 음악 — 폐장 음악과는 다른 단순한 피아노 화음이 끝까지 끊기지 않고 이어진다. / 환경 음향 — 한지석의 녹음 파일이 마지막 문장을 재생한다. / 정세린이 확인서에 펜을 내려놓는다. / 행동 개요 — 한지석의 사망과 정세린의 중상을 같은 살인 사건의 두 결과로 확정하고 세 공범의 지시·차단·은폐 책임을 기록한다.]*

*[지문: 빈 의자 앞에는 '한지석'이라는 이름이, 그 옆 정세린의 의자 앞에는 '생존 증인'이라는 표식이 놓인다.]*

*[지문: 한 사람은 돌아오지 못했고, 한 사람은 살아서 순서를 말했다.]*

**화면 문구**
피해 1: 한지석 사망 / 피해 2: 정세린 중대한 신체 손상

**한서윤** *(이름과 역할을 같은 속도로 나열해 공동 책임을 흐리지 않는다.)*
오빠의 죽음과 세린 씨의 부상을 나눠 기록하면 안 돼요. 강태수가 지시하고, 오민재가 퇴로를 막고, 박도윤이 신호와 기록을 바꾼 하나의 사건이에요.

**정세린** *(증언의 한계를 약점이 아닌 정확성으로 말한다.)*
제가 본 건 얼굴이 아니었어요. 그런데도 단추와 음악과 원본이 제가 본 순서를 지켜 줬어요.

**한지석(녹음)** *(장면 2의 녹음 끝부분이 선명하게 재생된다.)*
누가 기록을 바꾸려 해도 순서는 남아야 해.

*[지문: 한서윤이 사건 기록의 제목을 '폐장 음악이 멈춘 7분'으로 저장한다. 정세린은 사망과 생존 항목이 같은 사건 번호 아래 있는지 확인한다.]*

**화면 문구**
