# 케이스 안의 이름 — Shooting Script

## 제작 기준

- 러닝타임: 25분 / 1,500초
- 화면 공간: 해솔중학교, 은하악기사, 푸른뜰아파트 주민센터
- 주 촬영 원칙: 케이스와 악기의 소유를 같은 프레임에서 자동 결합하지 않는다. 표식은 필요 시에만 Insert로 보여 준다.
- 정보 통제: 기증 바이올린 실물은 SCN-09 전까지 촬영하지 않는다. SCN-07은 수리표와 잠긴 작업실 문만 보여 준다.
- 피해 묘사: 지안과 민서의 표정은 누명과 상실의 결과를 전달하되 굴욕을 반복 소비하지 않는다.

## 핵심 소품 Continuity

| 소품 | 외형 | 최초 공개 | 최종 기능 |
|---|---|---|---|
| 검은 하드 케이스 | 흰 학교 자산 스티커 | SCN-01 | 겉의 소유와 내부 소유를 분리하는 중심 물건 |
| 민서 가족 바이올린 | 꽃잎 긁힘 | SCN-02 | 실제 소유자 확인 |
| 민서 활 | 손잡이의 파란 실 | SCN-02 | 오주리의 선행지식 입증 |
| 자수 천 | 외할머니 이름 첫 글자 | SCN-02 | 민서의 정서적·물리적 소유 확인 |
| 붉은 보관 케이스 | 자산표 없음 | SCN-02 | 해인 개인 악기의 중간 위치 |
| 종이 수리표 | 누런 복사용지, 한 필압 | SCN-07 | 기증품의 사전 수리 독립 증거 |

## SCN-01 — 누명의 모양

- Segment: SEG-001~SEG-004 / 00:00~02:35
- Location: 학교 행정실 겸 준비실
- Cast: 지안, 배혜린, 교감, 최동수, 복도 학생 엑스트라
- Objective: 케이스 자산표, 오해된 문장, 공용 어깨받침이 지안을 향한 초기 혐의를 만든다.
- Blocking: 배혜린은 교감 옆, 지안은 빈 악기장과 마주 보는 반대편에 둔다. 지안이 출입카드를 반납할 때 복도 학생의 시선이 열려 있는 문을 통과한다.
- Coverage: 빈 악기장 Wide → 사진 속 스티커 Insert → 조사서의 ‘및’ Insert → 에코백 Top Shot → 카드 반납 Close.
- Sound: 형광등, 펜, 금속 캐비닛. 음악은 Panel 전환 전까지 억제한다.
- Continuity Check: 자산 스티커는 케이스 외부에만 보이고 악기 고유 번호는 보여 주지 않는다.

## SCN-02 — 주인이 알아보는 것

- Segment: SEG-005~SEG-007 / 02:35~04:50
- Location: 학교 복도와 음악실
- Cast: 지안, 민서
- Objective: 민서 개인 악기의 정서적 가치와 세 가지 소유 표식을 공정하게 공개한다.
- Blocking: 민서는 젖은 천 케이스를 몸 쪽에 붙이고, 지안은 바닥에 놓지 않도록 밑면을 받친다. 두 하드 케이스는 화면 뒤쪽에 나란히 둔다.
- Coverage: 젖은 지퍼 Macro → 꽃잎 긁힘 → 파란 실 매듭 → 자수 천 → 검은·붉은 케이스 Two Shot.
- Performance: 민서는 오디션 얘기에서 주변을 먼저 확인한다. 지안은 문제 해결 속도가 빠르지만 허가 절차를 건너뛰는 습관을 보인다.
- Continuity Check: 아직 내용물 교체를 보여 주지 않는다.

## SCN-03 — 너무 잘 정리된 증언

- Segment: SEG-008~SEG-010 / 04:50~07:45
- Location: 학교 소회의실
- Cast: 지안, 오주리, 배혜린, 최동수, 교감
- Objective: 파란 실, ‘해인이 케이스’, 출입 부인의 세 언어·행동 모순을 나란히 놓는다.
- Blocking: 진술자는 같은 의자를 교대하고 지안은 프레임 가장자리에 고정한다. 최동수의 배송 스티커는 관객이 볼 수 있으나 조사자는 즉시 집지 않는다.
- Coverage: 각 진술 Medium 고정 → 손·물컵·탁자 모서리 Reaction Insert → 세 진술 Split Screen.
- Sound: 의자 마찰음을 진술자 교대 Motif로 쓴다.
- Continuity Check: 오주리는 케이스 반출을 부인하지만 파란 실을 정확히 말한다.

## SCN-04 — 보호라는 침묵

- Segment: SEG-011~SEG-012 / 07:45~09:45
- Location: 제2연습실
- Cast: 민서, 배혜린, 지안, 교감
- Objective: 민서의 실제 거짓말과 지안의 보호성 침묵을 보여 주되 절도 공모와 분리할 여지를 남긴다.
- Blocking: 배혜린과 조사서는 민서 정면, 지안은 문 옆에 둔다. 오디션 안내문이 지안 시선 뒤에 들어오게 한다.
- Coverage: 서명 펜 Extreme Close → 민서와 지안의 Eye-line 불일치 → 문 위 갈라지는 그림자.
- Performance: 지안의 고개 젓기는 의미가 하나로 고정되지 않도록 작게 연기한다.

## SCN-05 — 두 번째로 바뀐 내용물

- Segment: SEG-013~SEG-014 / 09:45~12:10
- Location: 제2연습실과 전날 음악실 Flashback
- Cast: 지안, 민서
- Objective: 지안·민서의 케이스 교체, 수선 목록, 문장의 실제 의미를 공개한다.
- Blocking: 현재의 수선 목록을 바닥 중심에 놓고 Match Cut으로 전날 두 케이스 Top Shot에 연결한다.
- Coverage: 검은 케이스의 미확인 갈색 악기 → 붉은 케이스 이동 → 민서 악기·활·천의 검은 케이스 이동 → 젖은 천 케이스가 에코백으로 이동.
- Sound: Flashback 진입 시 빗물이 떨어지는 소리, 현재 복귀 시 종이 넘기는 소리.
- Continuity Check: 옮겨진 갈색 악기를 해인 개인 악기로 확정하는 표식은 아직 강조하지 않는다.

## SCN-06 — 붉은 케이스의 악기

- Segment: SEG-015~SEG-017 / 12:10~15:00
- Location: 음악실 악기장
- Cast: 지안, 민서, 배혜린, 교감
- Objective: 붉은 케이스에서 해인 개인 악기를 확인해 지안 이전의 내용물 부재 가설을 연다.
- Blocking: 배혜린이 손잡이를 막고, 교감이 손을 떼어 걸쇠를 연다. 민서는 소유 표식이 없음을 직접 확인한다.
- Coverage: 두 걸쇠 Sequential Close → 꽃잎 긁힘이 없는 줄걸이 → 해인 연습표와 조개 장식 → 배혜린이 민서를 먼저 보는 Reaction.
- Continuity Check: 배혜린의 대체 배치 행위는 말하거나 Flashback으로 보여 주지 않는다.

## SCN-07 — 종이가 기억한 날짜

- Segment: SEG-018~SEG-019 / 15:00~17:25
- Location: 영업 중인 은하악기사
- Cast: 지안, 나은주, 손님 엑스트라
- Objective: 나은주의 자기보호 거짓말을 해소하고 사건 전 수리표를 공개한다.
- Blocking: 거리 유리문은 열어 두고 작업실 문만 잠근다. 지안은 수리표를 가져가지 않고 계산대 건너에서 확인한다.
- Coverage: 송진 상자 낙하 → 서랍 열쇠 → 누런 수리표 필압과 네 항목 Insert → 잠긴 작업실 문.
- Sound: 영업 공간의 생활음과 버스 통과음을 유지한다.
- Continuity Check: 수리 중인 기증 바이올린은 프레임·반사면·그림자에도 노출하지 않는다.

## SCN-08 — 지워졌던 목격자

- Segment: SEG-020~SEG-022 / 17:25~20:25
- Location: 학교 현관과 관리실
- Cast: 지안, 최동수, 학생·택배기사 엑스트라
- Objective: 최동수의 택배 거짓말과 오주리 반출 목격을 분리한다.
- Blocking: 최동수가 장부를 들고 실제 목격 지점까지 걷는다. 학교 출입은 계속 열려 있어 물리적 고립이 없음을 보인다.
- Coverage: 개인 택배 상자 → 장부·기사 영수증 → 현관 동선 Follow → 스티커 방향 재연.
- Performance: 최동수는 ‘안은 못 봤다’에서 자기 지식의 한계를 분명히 한다.

## SCN-09 — 케이스에서 이름을 떼다

- Segment: SEG-023~SEG-024 / 20:25~22:50
- Location: 주민센터 공개 조사실
- Cast: 지안, 민서, 배혜린, 오주리, 최동수, 나은주, 교감, 방청 엑스트라
- Objective: 세 악기의 실제 위치와 두 책임자의 선택을 독립된 비기술 근거로 재구성한다.
- Blocking: 테이블을 세 구획으로 나누고 각 악기를 `기증품 / 해인 개인 / 민서 가족` 앞에 놓는다. 민서의 파란 실 활이 마지막에 배혜린과 오주리 사이를 가른다.
- Coverage: 기증 명판·수리 부위 → 붉은 케이스 악기 → 검은 케이스 개봉 → 꽃잎·파란 실·자수 천 → 두 문서 Side-by-side → 두 책임자의 침묵.
- Performance: 오주리의 인정은 짧고 방어적으로 처리한다. 결론은 자백보다 이미 공개된 세 근거에 둔다.
- Continuity Check: 실제 기증품은 이 Scene에서 처음 화면에 등장한다.

## SCN-10 — 이름표 없는 복도

- Segment: SEG-025~SEG-026 / 22:50~25:00
- Location: 주민센터 공개 오디션 로비·복도·연습실
- Cast: 지안, 민서, 진행요원, 참가자·심사위원 엑스트라
- Objective: 제도적 승리보다 책임을 받아들인 이별과 민서의 선택 회복으로 마무리한다.
- Blocking: 지안은 문밖 선을 넘지 않고, 민서는 직접 자기 케이스를 열고 무대에 들어간다.
- Coverage: 수선된 지퍼 → 꽃잎 긁힘 → 파란 실 → 열린 문 → 지안의 작은 엄지 → 마지막 음 뒤 박수.
- Sound: 마지막 20초는 현장 연주와 박수만 사용한다. 감정을 유도하는 해설을 추가하지 않는다.
- Continuity Check: 학교 기록 정정, 구조, 자동 폭로 장면을 넣지 않는다.
