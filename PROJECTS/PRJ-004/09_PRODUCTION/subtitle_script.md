# PRJ-004 Subtitle Script

최종 Broadcast Master의 실제 발화만 편집 구간별로 옮긴 자막 원고다. 구간 Timecode는 자막 노출 길이가 아니라 해당 Segment의 편집 범위를 뜻하며, 개별 자막의 In/Out은 녹음·연기 호흡에 맞춰 후반 작업에서 확정한다.

## 운용 원칙

- 배우 대사, Narration, 외부 Panel 발화를 원문 그대로 사용한다.
- 행동 지시, SFX, Replay, Graphic 문구는 Dialogue Subtitle에서 제외한다.
- 화자 표기는 작업용이며 최종 화면에서는 Channel Caption Style에 맞춰 제거하거나 축약한다.
