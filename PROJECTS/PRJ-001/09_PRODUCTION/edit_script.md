# PRJ-001 편집 대본

## 전체 리듬

- 목표 길이: 24분. 장면당 3분을 기준으로 하되 SCN-06과 SCN-07의 연결은 끊지 않는다.
- 리액션 총량은 전체의 약 20%로 유지한다.
- 내레이션은 화면이 이미 전달한 장소·행동을 반복하지 않고 의미 전환에만 사용한다.

## 편집 큐

| 시점 | 장면 | 편집 지시 | 유지 질문 |
|---|---|---|---|
| 00:00 | SCN-01 | 폭풍 와이드에서 21:49 모니터 인서트로 하드 컷 | 마지막 무전 뒤 어디로 갔는가? |
| 03:00 | SCN-02 | 방파제와 건물 내부를 2분할 교차 편집 | 어느 수색이 맞는가? |
| 06:00 | SCN-03 | 우량계 펄스와 저류조 손동작을 매치 컷 | 누가 센서를 움직이는가? |
| 09:00 | SCN-04 | 21:41과 21:49를 같은 프레임에 4초 유지 | 사건의 기준 시간은 언제인가? |
| 12:00 | SCN-05 | 장화 밑창 공개 직후 음악을 끊고 타격음을 전면 배치 | 신호는 어디에서 오는가? |
| 15:00 | SCN-06 | 남은 시간을 자막 대신 무전 대사와 수위 상승으로 표현 | 제한 시간 안에 열 수 있는가? |
| 18:00 | SCN-07 | 해치 개방부터 로비 도착까지 공간 연속성을 우선 | 구조와 원인 확인이 가능한가? |
| 21:00 | SCN-08 | 사건 분류 문구가 수정되는 과정을 생략 없이 보여 줌 | 권한은 오류를 어떻게 정정하는가? |

## 음향 큐

- 신호음은 모든 장면에서 동일한 3단·2장 리듬을 사용한다.
- SCN-04 패킷 시각 공개와 SCN-05 장화 반전에는 효과음을 넣지 않는다.
- 마지막 녹색 펄스 뒤 2초 무음 후 종료한다.
