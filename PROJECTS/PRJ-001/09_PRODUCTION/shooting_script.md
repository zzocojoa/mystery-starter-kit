# PRJ-001 Shooting Script — 폭풍이 꺼지기 23분 전

## 제작 기준

- 총 Runtime: 25분 / 1,500초
- 화면비: 16:9
- 현재 사건: 차가운 청록 계열, 손전등과 비상등 중심
- 데이터 화면: 중립 회색, 핵심 시각만 황색 강조
- External Panel: 사건 공간과 분리된 암청색 스튜디오, 단서 그래픽만 공유
- 한준호의 정확한 위치와 신호 발생 행동은 `SEG-016` 전까지 촬영하거나 삽입하지 않는다.
- Character Reaction은 Drama 카메라 안에서 처리하고 Panel Reaction과 편집상 혼용하지 않는다.

## SCN-01 — 마지막 무전

### SEG-001 / NARRATION / 50초

- SHOT-001: 폭풍 속 섬과 게스트하우스 외경, 8초 와이드.
- SHOT-002: 끊어진 전력선과 흔들리는 안테나, 7초 매크로 몽타주.
- SHOT-003: 재난상황실 다중 화면으로 느리게 푸시인, 25초.
- SHOT-004: 윤서하의 시선과 서로 다른 기록 두 개를 교차, 10초.
- AUDIO: Narration 우선. 저장 음성 잔향과 낮은 바람은 대사 아래 -18 LUFS.

### SEG-002 / DRAMA / 120초

- SHOT-005: 붉게 점멸하는 상황판 인서트. `주 업링크 단절`과 `마지막 수신 표시`를 한 프레임에 둔다.
- SHOT-006: 윤서하 미디엄. 호출 버튼을 누르는 손과 헤드셋을 교차한다.
- SHOT-007: 빈 중계실 원격 CCTV. 지하 복도는 노출을 낮춰 문 너머가 보이지 않게 한다.
- SHOT-008: 저장 음성이 잘릴 때 화면은 중계실 의자에 머문다. 한준호의 현재 모습은 사용 금지.
- SHOT-009: Character Reaction 클로즈업. 호출이 실패해도 감정을 과장하지 않는다.
- AUDIO: 천둥 뒤 0.8초 무음으로 금속문 소리를 분리한다.

### SEG-003 / PANEL_REACTION / 40초

- CAM-P3-A → CAM-P1-A → CAM-P2-A 순서로 질문·확인·감정 반응을 연결한다.
- REPLAY 10초: 마지막 무전 화면을 다시 보여 주되 패킷 생성 시각은 가린다.
- GRAPHIC 8초: 두 시각 사이에 물음표를 표시하고 방파제와 복도를 2분할한다.
- HOLD 4초: PANEL-02의 마지막 문장 뒤 세 패널 표정을 차례로 잡는다.

## SCN-02 — 두 개의 수색

### SEG-004 / DRAMA / 135초

- SHOT-010: 현관에서 방파제로 이어지는 장화 자국 트래킹.
- SHOT-011: 밑창 결손은 빗물로 흐리게 촬영해 소유자를 식별할 수 없게 한다.
- SHOT-012: 오미라의 열쇠와 손그림 도면 클로즈업.
- SHOT-013: 박대식과 오미라를 같은 높이의 투숏으로 구성해 어느 주장도 시각적으로 확정하지 않는다.
- SHOT-014: 화면 분할. 왼쪽은 방파제 수색, 오른쪽은 건물 내부 진입.
- AUDIO: 파도와 실내 누수음을 좌우 채널로 분리한다.

### SEG-005 / PANEL_REACTION / 45초

- CAM-P2-A 단독에서 PANEL-03 반문 투숏, PANEL-01 정리 와이드로 전환한다.
- REPLAY 12초: 젖은 장화 자국과 오미라의 손짓을 번갈아 보여 준다.
- GRAPHIC 9.8초: `물리 흔적`과 `현장 기억`을 동일 크기로 배치한다.
- PAUSE 4초: 반문 전후 짧은 호흡과 오미라의 경고 화면을 보존한다.

## SCN-03 — 죽지 않은 펄스

### SEG-006 / NARRATION / 45초

- SHOT-015: 꺼진 장비 랙 사이 녹색 릴레이 불빛만 천천히 드러낸다.
- SHOT-016: 윤서하와 오미라의 화면을 분할하되 발신 주체의 장소는 삽입하지 않는다.
- AUDIO: 릴레이 클릭을 Narration 문장 사이에 두어 규칙성을 들려준다.

### SEG-007 / DRAMA / 100초

- SHOT-017: 우량계 릴레이와 강우계 눈금을 번갈아 촬영.
- SHOT-018: 파형이 짧게 세 번, 길게 두 번 반복되는 모니터 그래픽.
- SHOT-019: 윤서하가 간격을 마킹하는 손. 화면에는 회로 종단 위치를 표시하지 않는다.
- AUDIO: 펄스마다 클릭음을 동일 음량으로 유지해 의도와 고장 모두 가능한 상태를 보존한다.

### SEG-008 / PANEL_REACTION / 45초

- CAM-P1-A 분석에서 CAM-P3-A 질문, CAM-P2-A 위험 반응으로 이동한다.
- REPLAY 10초: Pulse 파형을 짧게 세 번, 길게 두 번 재생한다.
- GRAPHIC 15.2초: `주 회선 OFF / 보조 회로 ACTIVE / 반복 간격`만 공개한다.
- HOLD 5초: 발신 주체를 보여 주지 않은 채 마지막 파형에 머문다.

## SCN-04 — 8분의 거짓말

### SEG-009 / DRAMA / 120초

- SHOT-020: 패킷 원본 헤더와 백업 게이트웨이 기록을 한 화면에 띄운다.
- SHOT-021: 생성 기록과 재생 기록을 차례로 확대한다.
- SHOT-022: 윤서하가 최초 분류 화면을 다시 여는 오버숄더.
- SHOT-023: 자신의 지시를 인정하는 대사는 정면 고정 숏으로 처리한다.
- SHOT-024: 사건 분류가 `위치 미상`으로 바뀌는 모니터 인서트.

### SEG-010 / PANEL_REACTION / 50초

- CAM-P3-B 반박, CAM-P1-B 재구성, CAM-P2-B 결과 반응으로 교차한다.
- REPLAY 12초: 방파제 수색 동선을 역순으로 되감는다.
- GRAPHIC 14.6초: 사람의 사건 시각과 시스템 재생 시각을 두 선으로 분리한다.
- HOLD 5초: 기존 동선 위 `전제 폐기` 표시에서 멈춘다.

## SCN-05 — 건물 안의 대답

### SEG-011 / DRAMA / 130초

- SHOT-025: 방파제에서 박대식의 장화 결손을 실물과 사진으로 매치 컷.
- SHOT-026: 보일러실 벽장이 밀리며 통기관이 드러나는 와이드.
- SHOT-027: 타격음에 맞춰 관 표면의 미세 진동을 매크로 촬영.
- SHOT-028: 우량계 파형과 현장 마이크 파형을 겹치는 그래픽.
- SHOT-029: 장판 아래 점검 해치 가장자리를 발견하되 아래 공간은 보여 주지 않는다.
- AUDIO: 마지막 긴 타격음은 앞선 신호보다 4 dB 낮춘다.

### SEG-012 / PANEL_REACTION / 50초

- CAM-P1-B 분석에서 PANEL-03 반문 뒤 세 패널 교차 숏으로 확장한다.
- REPLAY 10초: 장화 소유 확인, Pulse, 배관 타격을 차례로 재생한다.
- GRAPHIC 14.2초: 펄스와 타격음을 하나의 리듬선으로 결합한다.
- HOLD 5초: `해안 실종 → 지하 고립` 가설 변화와 지하 도면을 유지한다.

## SCN-06 — 해일 4분 전

### SEG-013 / NARRATION / 40초

- SHOT-030: 해치, 도면, 오미라의 메모, 상황실 화면을 빠른 4분할로 연결.
- AUDIO: 낮은 경보음이 절단기 시동음으로 자연스럽게 이어진다.

### SEG-014 / DRAMA / 130초

- SHOT-031: 지렛대가 미끄러지는 손과 부식된 경첩 클로즈업.
- SHOT-032: 상황실 경보와 현장 침수 높이를 교차.
- SHOT-033: 윤서하의 승인 대사는 고정 숏, 박대식의 시간 답변은 핸드헬드.
- SHOT-034: 절단 불꽃은 렌즈 보호 필터를 사용하고 배우 얼굴과 분리 촬영.
- SHOT-035: 철판이 들려 찬 공기가 나오지만 통로 안 인물은 촬영하지 않는다.
- SAFETY: 실제 침수 공간 대신 수조 세트와 발목 깊이 물을 사용한다.

### SEG-015 / PANEL_REACTION / 35초

- CAM-P2-B 위험, CAM-P1-C 숫자 확인, CAM-P3-C 결론을 빠르게 연결한다.
- B-ROLL 12초: 해치로 이동하는 구조대와 침수 높이를 교차한다.
- GRAPHIC 6.8초: 150초 Countdown과 해일 도달선을 겹친다.
- OUT 3초: 숫자가 150에서 149로 바뀌는 순간 현장으로 컷한다.

## SCN-07 — 사라지지 않은 사람

### SEG-016 / DRAMA / 160초

- SHOT-036: 로프 하강을 위에서 내려다본 숏. 수조 세트 깊이는 허벅지 이하로 제한.
- SHOT-037: 단 한 번의 타격 뒤 손전등 빔이 공간을 훑는다.
- SHOT-038: 한준호의 얼굴은 이 숏에서 처음 공개한다. 젖고 지쳤지만 신체 훼손 이미지는 사용하지 않는다.
- SHOT-039: 방화문 수동 레버의 부식 상태를 증거 인서트로 촬영.
- SHOT-040: 우량계 레버와 통기관을 한준호의 설명에 맞춰 짧게 재현한다. 이전 Scene 회상 삽입 금지.
- SHOT-041: 정전 뒤 휴대전화 조명만으로 인양 동선을 따라간다.
- SHOT-042: 구조 완료 시각 확인은 윤서하와 현장 영상의 투 프레임.
- SAFETY: 배우의 얼굴을 물에 잠기게 하지 않으며, 저체온·호흡 이상 연기는 의료 자문 범위 안에서 절제한다.

### SEG-017 / PANEL_REACTION / 30초

- CAM-P2-C 안도, CAM-P1-C 기록, CAM-P3-C 경고로 이어 간다.
- REPLAY 8초: 구조 완료 화면과 두 신호의 주체 확인을 짧게 묶는다.
- GRAPHIC 4.2초: 최초 분류 시각에 붉은 정정 표시를 겹친다.
- HOLD 3초: `왜 늦었는가` 질문과 세 패널의 가라앉은 표정을 남긴다.

## SCN-08 — 정정된 사건

- SHOT-043: 구조 뒤 로비의 정적인 와이드와 여러 기록 화면을 느리게 교차.
- SHOT-044: 서하의 시선에서 시설 로그, 현장 메모, 구조 기록을 차례로 본다.

### SEG-020 / PANEL_REACTION / 30초

- GRAPHIC 8초: 정정 전후 사건명을 나란히 보여 준다.
- HOLD 3.2초: 기록 저장음 뒤 세 패널의 정적을 유지한다.
- END 2초: `구조 성공`과 `기록 정정`을 같은 무게로 두고 타이틀 아웃한다.
