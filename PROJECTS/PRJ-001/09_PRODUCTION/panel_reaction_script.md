# PRJ-001 Production Panel Reaction Cue

## RSEG-001 / SEG-003 / 02:50–03:30

- FUNCTION: HYPOTHESIS_GENERATION
- SPEAKERS: PANEL-03 → PANEL-01 → PANEL-02
- SPOKEN ESTIMATE: 18.0초 / 45단어 / 150 WPM
- CAMERA: CAM-P3-A 질문, CAM-P1-A 확인, CAM-P2-A 감정 연결
- TIMING: 무전 Replay 10초 + 두 시각 Graphic 8초 + 표정 Reaction Hold 4초
- DELIVERY: PANEL-01의 “잠깐만”은 말을 끊는 속도로 받고, PANEL-02는 사람의 위험으로 연결한다.

[PANEL-03] “21시 49분이 실제 발신 시각이라는 확인부터 필요합니다. 표시가 늦게 붙은 것이라면 방파제 수색은 출발점부터 틀릴 수 있어요.”

[PANEL-01] “잠깐만, 그러면 화면의 시각과 사람이 무전을 보낸 시각을 같은 것으로 본 게 첫 단추네요?”

[PANEL-02] “맞아요. 숫자는 정확해 보여도 늦게 도착한 숫자라면, 그 사이 안에 남은 사람은 수색에서 지워집니다.”

## RSEG-002 / SEG-005 / 05:45–06:30

- FUNCTION: EMOTIONAL_REACTION
- SPEAKERS: PANEL-02 → PANEL-03 → PANEL-01
- SPOKEN ESTIMATE: 19.2초 / 48단어 / 150 WPM
- CAMERA: CAM-P2-A 시작, PANEL-03 반문에서 투숏, PANEL-01 정리에서 세 사람 와이드
- TIMING: 장화·손짓 Replay 12초 + 증거 비교 Graphic 9.8초 + 교차 발화 Pause 4초
- DELIVERY: 오미라를 정답 제공자로 단정하지 않고 물리 흔적과 현장 기억을 동시에 검증한다.

[PANEL-02] “장화 자국은 당장 따라가고 싶게 만들지만, 오미라의 경고는 오래 겪은 사람만 아는 위험이죠. 둘 중 하나를 너무 빨리 버리면 사람이 지워질 수 있습니다.”

[PANEL-03] “아니, 근데 기억만 믿고 바깥 흔적을 버리는 것도 위험하지 않나요?”

[PANEL-01] “그래서 둘 중 하나를 고르는 게 아니라, 장화의 주인과 오미라가 기억한 동선을 각각 확인해야 합니다.”

## RSEG-003 / SEG-008 / 08:55–09:40

- FUNCTION: ANOMALY_DETECTION
- SPEAKERS: PANEL-01 → PANEL-03 → PANEL-02
- SPOKEN ESTIMATE: 14.8초 / 37단어 / 150 WPM
- CAMERA: CAM-P1-A 분석, CAM-P3-A 질문, CAM-P2-A 위험 반응
- TIMING: Pulse Replay 10초 + 반복 간격 Graphic 15.2초 + 파형 Reaction Hold 5초
- DELIVERY: 신호 주체를 확정하지 않고 반복 간격이 고장 가설과 맞지 않는다는 점만 공유한다.

[PANEL-01] “주 회선은 끊겼는데 별도 회로의 펄스는 반복됩니다. 폭우가 원인이라면 왜 같은 간격이 되풀이되는지 설명해야 합니다.”

[PANEL-03] “잠깐, 단순 고장이라면 간격이 이렇게 반듯할 이유가 없다는 거죠?”

[PANEL-02] “누가 안에서 보내는 신호라면 지금도 기다리고 있다는 뜻이고요. 이건 소음으로 넘길 수 없어요.”

## RSEG-004 / SEG-010 / 11:40–12:30

- FUNCTION: CONTRADICTION_DETECTION
- SPEAKERS: PANEL-03 → PANEL-01 → PANEL-02
- SPOKEN ESTIMATE: 18.4초 / 46단어 / 150 WPM
- CAMERA: CAM-P3-B 반박, CAM-P1-B 재구성, CAM-P2-B 결과 반응
- TIMING: 기존 동선 Replay 12초 + Timeline Graphic 14.6초 + 정정 표시 Hold 5초
- DELIVERY: 기존 수색 논리를 반박하되 윤서하 개인을 조롱하지 않고 판단의 전제를 겨냥한다.

[PANEL-03] “이제 21시 49분은 사람의 시간이 아니라 시스템이 재생한 시간입니다. 그렇다면 그 시각 뒤의 동선을 찾는 수색 논리는 성립하지 않아요.”

[PANEL-01] “그러면 기준점을 7분 앞당겨야 해요. 패킷 생성 직전 건물 안에서 무엇이 닫혔는지부터 봐야 합니다.”

[PANEL-02] “밖으로 나간 사람을 찾던 화면이, 안에 갇힌 사람을 일곱 분 늦게 만든 셈이네요.”

## RSEG-005 / SEG-012 / 14:40–15:30

- FUNCTION: HYPOTHESIS_REVISION
- SPEAKERS: PANEL-01 → PANEL-03 → PANEL-02 → PANEL-01
- SPOKEN ESTIMATE: 20.8초 / 52단어 / 150 WPM
- CAMERA: CAM-P1-B 분석, PANEL-03 반문부터 세 사람 투숏 교차
- TIMING: 세 단서 Replay 10초 + 결합 Graphic 14.2초 + 지하 도면 Hold 5초
- DELIVERY: 반대 질문을 거친 뒤 해안 실종 가설을 지하 고립 가설로 명시적으로 바꾼다.

[PANEL-01] “장화 자국은 박대식의 것이고, 펄스와 타격음은 같은 리듬입니다. 이제 가장 적은 가정은 누군가 지하 설비 구역에서 두 경로로 신호를 보냈다는 쪽입니다.”

[PANEL-03] “아니, 근데 우연히 같은 리듬일 가능성은요?”

[PANEL-02] “세 번 짧게, 두 번 길게가 두 곳에서 반복됐어요. 우연보다 구조 요청으로 보는 게 사람을 살리는 판단입니다.”

[PANEL-01] “동의해요. 가설을 바꿉니다. 해안 실종이 아니라 지하 고립입니다.”

[PANEL-03] “그러면 더 따질 시간은 없네요. 틀릴 위험보다 늦을 위험이 커졌습니다.”

[PANEL-01] “그리고 다음 당직자가 같은 숫자를 볼 때 무엇부터 의심해야 하는지도요.”
